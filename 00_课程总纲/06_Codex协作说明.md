# Codex 协作说明

## 推荐使用方式

把本资料库作为一个独立项目目录交给 Codex。

建议先让 Codex 读：

1. `README.md`
2. `00_课程总纲/`
3. `00_课程总纲/11_单源一致性约定.md`
4. 某一个需要完善的章节文件

不要一上来让 Codex “完善全部课程”。更好的方式是一次只处理一个明确任务。

## 推荐任务粒度

### 好任务

- “请完善第 1 章的课程讲解稿，保持务实、温和、可直接分享。”
- “请为第 5 章补充 3 个课堂案例，适合跨境电商 Listing 训练。”
- “请把模板库里的《广告数据复盘表》改成更适合学员填写的版本。”
- “请检查第 1 周所有章节是否都有交付物和反馈方式。”

### 不好的任务

- “帮我完善全部。”
- “把课程做得更高级。”
- “给我写得震撼一点。”
- “加一些自动化系统。”

## 推荐工作流

1. 先让 Codex 阅读项目说明。
2. 再让 Codex 输出修改计划。
3. 你确认方向后，再让它改文件。
4. 改完后，让它列出改动摘要。
5. 你人工检查语言是否符合课程气质。

## 修改检查清单

Codex 每次修改后，建议检查：

- 有没有夸张表达。
- 有没有无法落地的空话。
- 有没有过多专业词。
- 是否每章都有一个具体交付物。
- 是否包含理念、实操、反馈、练习。
- 是否保留“先完成，再优化，再复用”的节奏。

## 建议给 Codex 的总提示词

```text
请阅读本项目的 README.md、00_课程总纲 文件夹和 00_课程总纲/11_单源一致性约定.md。
你的任务是协助完善《AI 跨境电商效能提升实战课》。
请保持课程风格务实、温和、清楚，不使用刺激性营销话术。
每次修改前先输出简短计划，修改后输出改动摘要。
当前先不要新增高级自动化内容，重点是个人提效、岗位提效和真实项目落地。
```
