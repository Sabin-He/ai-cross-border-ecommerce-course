# 单源一致性约定（Source of Truth）

本文件定义课程资料库的"单源"策略，解决同一章内容在源章节、实操手册、TCI 化教材三处都有副本、容易互相不一致的问题。

> 背景：课程经过 Codex 多轮迭代后，同一章目前可能同时出现在三处：
>
> 1. `01_第1周_AI基础提效周/Day0X_*.md` 等源章节
> 2. `09_章节实操手册/Day0X_*_实操手册.md`
> 3. `10_TCI化教材系统/01_学员主教材/第N周_*.md` 等 TCI 视图
>
> 如果不定规则，任何一次内容更新都要手动同步三处，迟早不一致。

---

## 一、三份文档的职责分工

| 视图 | 文件夹 | 职责 | 是否 SoT |
| --- | --- | --- | --- |
| **源章节** | `01_第1周_AI基础提效周/`、`02_第2周_AI岗位实战周/`、`03_第3周_AI落地陪跑周/` | 章节的**原始真源**：问题引入、核心概念、方法论、案例、误区、小结 | **✅ 是 SoT** |
| **实操手册** | `09_章节实操手册/` | 学员动手视图：step by step 指引、可填写工作纸、4 条专用提示词 | ❌ 是派生视图 |
| **TCI 学员主教材** | `10_TCI化教材系统/01_学员主教材/` | 出版视图：按周打包、删掉冗余解释、强调"做什么 / 产出什么" | ❌ 是派生视图 |
| **TCI 工作簿** | `10_TCI化教材系统/02_实操工作簿/` | 派生自实操手册的"可填写版" | ❌ 是派生视图 |
| **TCI 讲师手册** | `10_TCI化教材系统/03_讲师手册/` | 派生自源章节 + 实操手册的"授课脚本视图" | ❌ 是派生视图 |

原则：**源章节是唯一真源。任何章节内容（概念、方法、案例、误区）的改动，必须先改源章节；实操手册与 TCI 视图从源章节派生而来。**

## 二、不同性质内容的归属

| 内容类型 | 归属 | 为什么 |
| --- | --- | --- |
| 章节核心概念 / 方法论 / 案例 / 误区 | 源章节 | 只应有一份，其余视图引用或精简 |
| 4 条章节专用提示词（拆任务 / 生成第一版 / 自评 / 模板化） | 实操手册 | 实操手册才是"可直接复制粘贴"的操作入口 |
| 可填写工作纸 | 实操手册 | 学员手写 / 打印用 |
| 课堂节奏、话术、时间分配、讲师提醒 | TCI 讲师手册 | 授课执行视图，源章节不关心课堂节奏 |
| 交付物评分标准（章 / 周 / 结营） | `06_评分与反馈/` 与 `10_TCI化教材系统/06_验收与评分系统/` | 评分单独维护，章节正文只做指向 |
| 模板骨架 | `04_模板库/` | 所有章节交付物的模板在此集中维护 |
| 提示词库 | `05_提示词库/` | 对外独立发布；章节内只引用 |
| 跨境电商脱敏数据样本 | `10_TCI化教材系统/05_案例与数据包/` | 所有章节共用的原材料 |

## 三、改动流程（必须遵守）

### 3.1 改章节正文（最常见）

1. 只改 `01_`、`02_`、`03_` 源章节文件。
2. 如果改动影响"做什么 / 产出什么"，同步更新：
   - `09_章节实操手册/Day0X_*_实操手册.md` 的 step by step 章节。
   - `10_TCI化教材系统/01_学员主教材/第N周_*.md` 里对应章节的 1–13 节。
3. 提交时在 commit message 里标明 `[sync: ch5]` 之类，便于追溯。

### 3.2 改提示词

- 章节内提示词：改 `09_章节实操手册/`。
- 通用提示词库：改 `05_提示词库/`。
- **禁止**把同一条提示词同时放在源章节正文和实操手册里——源章节只引用链接。

### 3.3 改评分或模板

- 评分标准：改 `06_评分与反馈/`（同时同步 `10_TCI化教材系统/06_验收与评分系统/`）。
- 模板骨架：改 `04_模板库/`。
- 源章节只写"本章交付物 = 《XX 表》"和指向模板库的链接，不复制表格本体。

### 3.4 改文件 / 目录名

必须跑 `tools/rename_roles.py` 或同类迁移脚本，保证三份视图里的路径引用同步更新。

## 四、给 AI 代理（Codex / Claude / Qoder）的指令约定

当你让 AI 代理"完善第 X 章"时，统一按以下顺序：

1. **先读** 源章节 + 实操手册 + TCI 主教材三份当前内容。
2. **先改源章节**，补充或重写必要段落。
3. **再生成或精简实操手册**，保证和源章节一致。
4. **最后同步 TCI 主教材**里对应章节的 13 节结构。
5. **每次修改都要报告三份文档的 diff**，便于人工验收。

禁止：只改其中一份视图而不同步其余两份。

## 五、下一阶段自动化（占位）

当三份副本内容趋于稳定后，应编写 `tools/sync_chapter_views.py`：

- 输入：源章节 Markdown。
- 输出：重建 `09_章节实操手册/` 对应文件与 `10_TCI化教材系统/01_学员主教材/` 对应段落。
- 派生规则的归口目录是 [`10_TCI化教材系统/08_出版与交付化/`](../10_TCI化教材系统/08_出版与交付化/00_出版与交付化说明.md)；其中"学员版精简重排规范"与"工作簿可填写化规范"仍在规划中，编写完成前，手动同步一律按本文件第三节流程执行。

在自动化完成前，手动同步必须遵守上面第三节流程。

打开一个章节前，问自己：

- [ ] 我要改的是"概念/方法/案例" → 去源章节。
- [ ] 我要改的是"step by step / 工作纸 / 专用提示词" → 去实操手册。
- [ ] 我要改的是"课堂时间分配 / 话术" → 去讲师手册。
- [ ] 我要改的是"评分标准" → 去评分与反馈目录。
- [ ] 我要改的是"模板骨架" → 去模板库。
- [ ] 改完后我同步了其他视图吗？有没有跑检查脚本？

如果答不上来，先回到本文件查职责分工，不要直接动笔。
