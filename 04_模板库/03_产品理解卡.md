# 产品理解卡

> **一句话定位**：在开始写 Listing / 投广告 / 定方案之前，先用这张卡把产品"讲清楚"。没讲清楚前的所有动作都是浪费。  
> **最低门槛**：12 个字段全部非空；"需要人工确认的信息"≥ 1 条。

---

## 一、使用流程（4 步）

1. **先自己写**：能答的字段先写，哪怕粗糙也行；真答不上来的留空，**不要让 AI 帮你编**。
2. **AI 补全**：用 [`../05_提示词库/02_产品理解提示词.md`](../05_提示词库/02_产品理解提示词.md) 喂 AI，让它**只补你标了"待查"的字段**。
3. **人工核验**：重点检查"产品限制或不足"、"竞品常见卖点"——这两栏 AI 最容易胡编。
4. **留问题**：把没查明、需供应链/老板决策的问题全部写到"需要人工确认的信息"列，下一步带着问题去对接。

---

## 二、填好的示例（P01·YogaLife Pro 6mm TPE 瑜伽垫）

| 项目 | 内容 |
| --- | --- |
| 产品名称 | YogaLife Pro 6mm TPE Yoga Mat（脱敏虚构） |
| 产品所属平台 | Amazon US（主）/ Shopify（次） |
| 目标用户 | 25-45 岁北美家庭瑜伽用户，70% 女性；每周练习 2-4 次；多数在家中客厅使用 |
| 用户使用场景 | 早晨起床后 20 分钟 yoga flow / 晚间睡前 10 分钟拉伸；部分带去 studio |
| 用户想解决的问题 | ① 普通垫太薄（膝盖痛） ② PVC 味道大 ③ 容易打滑 ④ 不好收纳 |
| 产品核心卖点 | ① 6mm 厚度，对膝盖友好 ② TPE 材质，无 PVC / latex 异味 ③ 双面防滑纹路 ④ 配收纳带 |
| 产品限制或不足 | ① 重量 2.3 lbs，比 3mm 款重 40%（便携性差） ② 颜色只有 3 色 ③ TPE 长期暴晒会变色 ④ 价格比入门款高 30% |
| 竞品常见卖点 | Liforme（对齐标记）/ Manduka Pro（终身保修）/ Gaiam（低价入门） |
| 我们的差异点 | 6mm 厚度 + TPE + 收纳带一体化；同价位里**无 PVC** 的不多 |
| 需要人工确认的信息 | ① TPE 耐用性数据（多少次对折不裂） ② 是否有 OEKO-TEX 认证 ③ 3 色库存分布 ④ 竞品 Liforme 当前售价 |
| AI 做了什么 | 归并 3 个竞品页面信息到"竞品常见卖点"；从 80 条评论中提炼 4 类痛点 |
| 人工做了什么 | 核对"产品限制"的 4 条是否都真实；删掉 AI 编造的一条"可水洗"（实际只能擦） |

## 四、验收标准

- [ ] 12 个字段全部非空（真空不下的写"待查-本周内补"）
- [ ] "产品限制或不足" ≥ 3 条（没有短板的产品 = 没想清楚的产品）
- [ ] "我们的差异点"不是"质量好/性价比高"这种空话，必须有具体对比维度
- [ ] "需要人工确认的信息" ≥ 1 条
- [ ] 人工修改记录 ≥ 1 行（0 行 = 没过脑子）

---

## 五、常见错误

| 错误 | 后果 |
| --- | --- |
| 目标用户写"所有女性" | Listing 打不到任何人 |
| 核心卖点和竞品卖点完全一样 | 无差异化，价格战 |
| 产品限制写"无" | 定位不清，广告投放浪费 |
| AI 编造参数直接采信（如"500g"但实际是 1.04kg） | Listing 误导 → 差评 |
| 没写"需要人工确认" | 后续反复回来补资料 |
