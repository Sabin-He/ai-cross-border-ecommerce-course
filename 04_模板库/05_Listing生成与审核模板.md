# Listing 生成与审核模板

> 本模板用在第 5 章《AI 辅助 Listing 初稿》。目标是把"AI 生成的 Listing"和"能发布上架的 Listing"之间那道人工关卡说清楚。
>
> 本章的 AI 输出**只负责给初稿**，审核清单才是决定能不能发的关卡。

---

## 一、使用流程（5 步）

1. 先填完 [`03_产品理解卡.md`](./03_产品理解卡.md) 和 [`04_竞品评论分析表.md`](./04_竞品评论分析表.md)。没有这两份材料，不要开始写 Listing。
2. 用 [`05_提示词库/04_Listing生成提示词.md`](../05_提示词库/04_Listing生成提示词.md) 生成初稿。
3. 把初稿粘贴到本模板"Listing 初稿"部分。
4. 一条一条对照"审核清单"勾选。
5. 没全部通过之前，**不要**上架。

---

## 二、填好的示例：瑜伽垫 YogaLife Pro

### 示例 · 标题

```
YogaLife Pro 6mm TPE Yoga Mat, Non-Slip Dual-Textured Exercise Mat with Carrying Strap, Eco-Friendly, 72" x 24", for Home Workout, Pilates, Floor Exercises
```

### 示例 · 五点描述

1. **[THICK & SUPPORTIVE] 6mm Cushioning** — absorbs pressure on knees, wrists and spine during floor poses and Pilates, while staying firm enough for balance work.
2. **[DUAL-TEXTURED NON-SLIP] Wave Top / Dot Bottom** — the wavy top grips hands and feet even when sweaty; the dotted underside holds the mat in place on hardwood and tile.
3. **[ECO-FRIENDLY TPE MATERIAL] 6P Free, SGS Tested** — no latex, no PVC, no strong rubber smell out of the box; safe for daily indoor use.
4. **[72" × 24" FULL-BODY COVERAGE] Fits Users Up to 6'0"** — enough length for tall users to stretch fully, and wide enough for full-body flows.
5. **[EASY TO CARRY & STORE] Includes Carrying Strap** — rolls up tight, strap included; light enough (2.2 lbs) to take to a studio or keep by the couch.

### 示例 · 产品描述（节选）

> Designed for daily indoor practice. The 6mm TPE core is firm enough for balance poses yet cushions your knees during floor work. The dual-textured surface keeps the mat stable on hardwood or tile — no slipping mid-flow. …

### 示例 · 后台关键词（Backend Search Terms）

```
yoga mat thick non slip   pilates mat   home workout mat   exercise mat for women   tpe yoga mat   eco friendly yoga mat   yoga mat 6mm   floor mat for home gym
```

### 示例 · 本 Listing 的"人工确认项"（AI 应主动标出）

- 产品是否真的通过 SGS 测试？证书号缺失。
- "Fits Users Up to 6'0'" 是否有实测依据？
- 是否需要注明洗涤方式？有 1 条竞品差评提到清洗掉色。

## 四、审核清单（发布前逐项勾选）

### 4.1 内容事实类

| 检查项 | 是否通过 | 修改建议 |
| --- | :---: | --- |
| 标题 / 五点中的功能描述是否和产品实物一致 | ☐ |  |
| 是否避免"最佳 / 第一 / 100% / 治愈 / 医疗"等夸大或医疗类用词 | ☐ |  |
| 是否避免涉及竞品名、平台名的对比用语 | ☐ |  |
| 材料 / 认证 / 尺寸是否有实物或证书支持 | ☐ |  |
| 是否避免"无理由退换"等超出实际售后承诺 | ☐ |  |

### 4.2 用户价值类

| 检查项 | 是否通过 | 修改建议 |
| --- | :---: | --- |
| 是否至少写出 2 个具体使用场景 | ☐ |  |
| 是否围绕目标用户真实痛点（来自评论分析表） | ☐ |  |
| 是否把卖点翻译成了"对用户意味着什么" | ☐ |  |
| 五点是否避免全部卖同一个点（例如 5 条都讲"厚") | ☐ |  |

### 4.3 表达质量类

| 检查项 | 是否通过 | 修改建议 |
| --- | :---: | --- |
| 语气是否自然，不像广告喊话 | ☐ |  |
| 长句是否拆成了用户能一眼扫完的短段 | ☐ |  |
| 关键词是否自然融入文本，而不是机械堆砌 | ☐ |  |
| 是否对非英语母语读者也读得懂（句子短、词汇常见） | ☐ |  |

### 4.4 平台合规类（必须另行人工复核）

| 检查项 | 是否通过 | 修改建议 |
| --- | :---: | --- |
| 标题字符数是否符合该类目上限 | ☐ |  |
| 是否避开本类目禁用词清单（如食品类"FDA approved"） | ☐ |  |
| 图片 / 视频在外链描述中是否真实存在 | ☐ |  |
| 商标 / 认证 logo 引用是否得到授权 | ☐ |  |

## 五、验收标准

- 4.1 内容事实类：**必须全部通过**，有任何一条存疑就不能发。
- 4.2 用户价值类：至少 3/4 通过，否则退回重写。
- 4.3 表达质量类：至少 3/4 通过。
- 4.4 平台合规类：**必须全部通过**，且标为"已人工复核"。

全部达标 = 可发布。任一"必须"未过 = 禁止发布。

---

## 六、常见错误

1. **直接照搬 AI 初稿发布**——五点描述的功能、认证信息几乎都可能被 AI 编造。
2. **删掉 AI 主动标出的"人工确认项"后就发了**——那恰恰是 AI 在告诉你"这里可能有假"。
3. **标题堆关键词到超出字符限制**——被平台截断后露出的内容反而尴尬。
4. **卖点写成参数**——例如"6mm 厚"而不是"6mm 厚能吸收压力、保护膝盖"。
5. **关键词重复**——后台关键词和五点、标题都写了同一个词，浪费曝光。
