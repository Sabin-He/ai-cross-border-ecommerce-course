# 通用提示词框架

## 适用场景

当你还没有专用提示词时，用这个框架把任务说清楚。适合整理资料、生成初稿、检查问题、改写成表格或清单。

## 输入变量

- 【角色】：例如跨境电商运营助理、广告复盘助手、客服 FAQ 整理助手。
- 【业务背景】：你正在处理的场景。
- 【具体任务】：这次只让 AI 做一件事。
- 【粘贴资料】：已经脱敏的原始资料。
- 【输出形式】：表格、清单、步骤、邮件草稿、SOP 等。

## 可复制提示词

```text
你是一名【角色】。

我正在做【业务背景】。

请你帮我完成【具体任务】。

已知信息如下：
【粘贴已脱敏资料】

请注意：
1. 不要编造资料中没有的信息。
2. 不确定的地方请标记“需要人工确认”。
3. 不要输出夸大效果、绝对承诺或平台规则无法确认的内容。
4. 如果资料不足，请先列出缺口，不要自行补全。
5. 输出要具体，避免空话。

请用【输出形式】输出，并额外列出：
- 需要人工确认的信息
- 不建议直接使用的内容
- 下一步人工修改建议
```

## 人工检查点

- [ ] 输入资料已脱敏。
- [ ] AI 没有编造未提供的信息。
- [ ] 输出中没有夸大效果或自动保证结果。
- [ ] 平台规则、价格、库存、补偿、预算等关键判断已人工确认。
- [ ] 最终内容经过人工修改。
