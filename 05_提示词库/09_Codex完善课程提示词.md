# Codex 完善课程提示词

## 完善单章

```text
请阅读 README.md、00_课程总纲/11_单源一致性约定.md 和当前章节文件。
请完善这个章节，让它更适合讲师直接分享。
要求：
1. 保持务实、温和、清楚。
2. 不使用刺激性营销话术。
3. 每个知识点都尽量对应一个动作。
4. 补充课堂示范话术。
5. 补充一个跨境电商场景案例。
6. 补充作业评分标准。
7. 不新增复杂自动化内容。
```

## 检查全周一致性

```text
请检查第【几】周所有章节文件。
重点检查：
1. 章节目标是否递进。
2. 是否每章都有交付物。
3. 是否每章都有实操和反馈。
4. 语言是否务实、温和。
5. 是否出现夸张表达。
6. 是否有术语未解释。
请先列出问题，再提出修改建议。
```

## 生成讲师逐字稿

```text
请根据当前章节，生成一版适合讲师讲课的逐字稿。
要求：
1. 语言自然，像讲师在课堂上说话。
2. 每 5-10 分钟有一次互动问题。
3. 不要说教，不要制造焦虑。
4. 讲解后要引导学员做实操。
```
