# 运营周报提示词

## 适用场景

用于 Day12，把运营数据和本周事项整理成“数据变化、原因假设、下周动作、风险提醒”的周报初稿。

## 输入变量

- 【业务范围】：店铺、产品线或渠道。
- 【本周数据】：已脱敏的关键数据。
- 【本周动作】：本周做过的主要运营动作。
- 【异常变化】：明显变化或需要解释的指标。
- 【下周重点】：下周必须推进的事项。

## 可复制提示词

```text
你是一个跨境电商运营周报整理助手。

请基于我提供的脱敏资料，帮我整理一份运营周报初稿。

业务范围：
【填写】

本周关键数据：
【粘贴已脱敏数据】

本周主要动作：
【填写】

异常变化或需要解释的指标：
【填写】

下周重点：
【填写】

任务：
1. 提炼本周 3 个最重要的变化。
2. 把原因写成“假设”，不要写成已经确认的事实。
3. 给出 1 到 3 个下周动作，每个动作要有负责人、时间和完成标准。
4. 列出需要人工确认的信息和风险提醒。

约束：
- 不要编造我没有提供的数据、事件或原因。
- 不要夸大增长或承诺结果。
- 不要处理客户、订单、账号、成本等敏感信息。
- 不确定的信息请写入“需要人工确认”。

输出格式：
| 模块 | 内容 |
| --- | --- |
| 本周关键变化 |  |
| 原因假设 |  |
| 下周动作 |  |
| 风险提醒 |  |
| 需要人工确认 |  |
```

## 人工检查点

- [ ] 数据口径和时间范围已人工确认。
- [ ] 原因没有被写成无证据结论。
- [ ] 下周动作可执行，有负责人和完成标准。
- [ ] 周报中没有客户、订单、账号、成本等敏感信息。
- [ ] AI 初稿已经人工修改。
