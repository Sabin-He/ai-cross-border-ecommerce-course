# 项目落地提示词组

## 适用场景

用于第 3 周 Day15 到 Day21，辅助学员完成一个真实小项目闭环：选项目、拆步骤、做 v1、收反馈、改 v2、固化模板、做 7 天计划、结营复盘。

## 通用敏感信息提醒

使用下面任何提示词前，先删除客户姓名、订单号、联系方式、账号、内部成本、广告账户截图、供应商报价等敏感信息。AI 可以帮助整理和起草，但最终选择、取舍和业务判断必须由人确认。

## 1. 项目选择提示词

```text
你是一个跨境电商运营项目筛选助手。

请基于我提供的脱敏资料，帮我评估几个候选项目，并输出项目选择表初稿。

我的岗位：
【填写】

当前最想改善的问题：
【填写】

本周可投入时间：
【填写】

候选项目：
1. 【填写】
2. 【填写】
3. 【填写】

每个项目已有资料：
【填写】

任务：
1. 按价值、难度、资料、周期四个维度比较候选项目。
2. 判断哪些项目范围过大，并给出缩小建议。
3. 推荐本周最适合完成的 1 个项目。
4. 列出需要人工确认的信息。

约束：
- 不要替我做最终决定。
- 不要编造资料中没有的信息。
- 不确定的信息写入“需要人工确认”。

输出格式：
| 候选项目 | 价值 | 难度 | 资料情况 | 周期 | 推荐程度 | 缩小建议 | 需要人工确认 |
```

## 2. 项目拆解提示词

```text
你是一个项目拆解助手。

请把下面项目拆成 5 到 7 个小步骤。

项目目标：
【填写】

最终交付物：
【填写】

已有资料：
【粘贴已脱敏资料】

本周可投入时间：
【填写】

任务：
1. 按“输入资料、动作、输出结果、人工检查标准”拆解。
2. 每一步控制在 30 到 90 分钟内能推进。
3. 标出哪些步骤适合 AI 辅助，哪些必须人工判断。

输出格式：
| 步骤 | 需要资料 | AI 辅助方式 | 输出结果 | 人工检查标准 | 预计用时 |
```

## 3. v1 生成提示词

```text
你是一个项目初稿助手。

请根据我的项目拆解表和脱敏资料，生成项目第一版 v1。

项目目标：
【填写】

项目拆解表：
【粘贴】

输入资料：
【粘贴已脱敏资料】

任务：
1. 输出 v1 骨架。
2. 填入核心内容。
3. 标出需要人工确认的地方。
4. 给出 2 到 3 个适合收集反馈的问题。

约束：
- 不要编造资料中没有的信息。
- 不要把待确认信息写成确定结论。
- v1 只求能看、能改、能收反馈。
```

## 4. 反馈修改提示词

```text
你是一个反馈整理助手。

请帮我把下面反馈分类，并建议修改优先级。

项目 v1 摘要：
【粘贴】

反馈内容：
【粘贴】

项目目标：
【填写】

任务：
1. 把反馈分为事实错误、结构问题、表达问题、业务建议、个人偏好。
2. 建议是否采纳，并说明理由。
3. 给出 v2 修改动作。
4. 标出需要人工判断的信息。

输出格式：
| 反馈 | 分类 | 建议是否采纳 | 理由 | v2 修改动作 | 需要人工判断 |
```

## 5. 模板固化提示词

```text
你是一个模板整理助手。

请帮我把项目 v2 提取成可复用模板。

项目 v2：
【粘贴】

使用场景：
【填写】

任务：
1. 提取固定结构。
2. 把每次要替换的内容改成【变量字段】。
3. 保留一个脱敏示例。
4. 列出使用前准备资料。
5. 列出使用后人工检查点。

约束：
- 不要保留具体客户、订单、账号、成本等敏感信息。
- 模板要能脱离原项目单独复用。
```

## 6. 7 天计划提示词

```text
你是一个 7 天行动计划助手。

请基于我的可复用模板，帮我制定 7 天 AI 使用计划。

模板名称：
【填写】

使用场景：
【填写】

每次可投入时间：
【填写】

任务：
1. 每天安排一个小动作。
2. 每个动作绑定真实工作场景。
3. 每天都要有一个小交付物。
4. 第 7 天安排复盘和模板更新。

输出格式：
| 日期 | 触发场景 | 小动作 | 预计用时 | 产出 | 复盘问题 |
```

## 7. 结营复盘提示词

```text
你是一个成果包整理助手。

请基于我提供的材料，帮我整理结营复盘初稿。

材料：
- 落地项目选择表：【粘贴摘要】
- 项目拆解表：【粘贴摘要】
- 项目 v1：【粘贴摘要】
- 反馈修改记录：【粘贴摘要】
- 项目 v2：【粘贴摘要】
- 模板固化表：【粘贴摘要】
- 7 天计划：【粘贴摘要】

任务：
1. 整理项目链路。
2. 总结 AI 辅助了哪些步骤。
3. 总结我做了哪些人工判断和修改。
4. 提炼 v1 到 v2 的变化。
5. 输出后续 7 天行动重点。

约束：
- 只写已经发生和可验证的变化。
- 不夸大效果。
- 不写敏感资料。
- 不把 AI 输出当最终结论。
```

## 人工检查点

- [ ] 最终选择由人确认。
- [ ] 项目范围一周内可完成。
- [ ] v1 标出了待确认内容。
- [ ] v2 记录了采纳和不采纳理由。
- [ ] 模板已经去敏感化。
- [ ] 7 天计划小到能执行。
- [ ] 结营复盘只展示可验证变化。
