# 通用作业评分表

适用于 21 个章节的大部分作业。建议先自评，再由同伴或讲师复评。

| 评分项 | 20 分：好结果 | 12 分：合格结果 | 6 分：需要修改 | 得分 |
| --- | --- | --- | --- | ---: |
| 问题清楚 | 明确写出要解决的业务问题、使用场景、对象和限制条件 | 能看出大致问题，但场景或对象不够具体 | 只有“帮我写/帮我分析”等模糊要求 |  |
| 资料完整 | 提供产品信息、平台、目标用户、已有素材或数据来源，并说明哪些是假设 | 提供部分背景，但缺少关键限制或资料来源 | 几乎没有背景，AI 只能凭空发挥 |  |
| AI 使用合理 | AI 负责整理、归纳、改写、初稿，人负责判断和取舍 | AI 做了主要草稿，但人工判断较少 | 把最终判断完全交给 AI |  |
| 人工修改 | 标出至少 2 处修改，并说明为什么改 | 有修改痕迹，但理由不清楚 | 直接复制 AI 输出，没有人工判断 |  |
| 业务可用性 | 结果能被真实工作继续使用，语气、格式、事实基本合适 | 结果能参考，但还需要明显补充 | 结果看起来完整，但不能直接用于工作 |  |
| 可复用性 | 沉淀成模板、清单、SOP 或提示词，下次能继续用 | 有可复用片段，但未整理成固定格式 | 只完成一次性结果，没有沉淀 |  |
| 风险控制 | 已检查敏感信息、夸大表达、平台合规和事实依据 | 检查了部分风险 | 未检查风险，可能误导或违规 |  |

## 总分判断

| 分数 | 判断 | 建议 |
| ---: | --- | --- |
| 120-140 | 可以作为示例作品 | 保存版本，并整理成模板 |
| 90-119 | 可以提交，但建议再改一轮 | 选择 1-3 个关键点优化 |
| 60-89 | 需要修改后再提交 | 回到输入资料和人工判断 |
| 60 以下 | 不建议交付 | 重新缩小问题，补足背景资料 |
