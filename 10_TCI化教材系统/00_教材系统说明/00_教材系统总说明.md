# TCI 化教材系统总说明

这个目录是《AI 跨境电商效能提升实战课》的教材化输出层。

原来的 `00_课程总纲/` 到 `09_章节实操手册/` 继续作为源资料库保留。本目录不替代源资料，而是把源资料重新整理成更适合教学、练习、复用和验收的教材系统。

## 为什么新增这一层

原资料库内容已经比较完整，但不同角色会看到同一批材料：

- 学员需要顺着读、跟着做。
- 讲师需要课堂节奏、话术和点评方式。
- 组织者需要成果验收、交付版本和复用工具包。

TCI 化重组的目的，是把这些角色的使用路径分开，让课程从“资料集合”变成“可交付教材系统”。

## 本目录包含什么

| 目录 | 用途 |
| --- | --- |
| `00_教材系统说明/` | 说明整套教材系统如何使用 |
| `01_学员主教材/` | 给学员阅读，讲清问题、方法和案例 |
| `02_实操工作簿/` | 给学员填写，完成每章交付物 |
| `03_讲师手册/` | 给讲师或讲师使用，提供课堂节奏和话术 |
| `04_模板与提示词工具包/` | 课后复用的模板、提示词和检查清单 |
| `05_案例与数据包/` | 课堂练习用的脱敏案例和样例资料 |
| `06_验收与评分系统/` | 单章、每周、结营成果的评分标准 |
| `07_交付版本索引/` | 记录可分享版本、内部版本和更新记录 |
| `08_出版与交付化/` | 交付版本冻结、术语、排版、样板日和 AI 代理执行规范 |

## 当前状态

TCI 化教材系统已覆盖三周主线：

- 第 1 周：个人基础提效单元。
- 第 2 周：岗位 AI 实战单元。
- 第 3 周：真实项目落地单元。

每周都已经整理出学员主教材、实操工作簿、讲师手册、工具包、案例包和评分标准。第 10 章《AI 辅助广告数据复盘》仍可作为数据类章节的完整样板，第 21 章《个人 AI 落地成果包》作为结营闭环样板。

## 使用原则

- 保留原始资料，不删除、不搬空源目录。
- **单源约定**：概念 / 方法 / 案例 / 误区的唯一真源是 `01_~03_` 源章节；本目录是 **派生视图**，不得先于源章节改动。详见 [`../../00_课程总纲/11_单源一致性约定.md`](../../00_课程总纲/11_单源一致性约定.md)。
- 新内容优先从源章节、实操手册、模板库、提示词库和评分反馈中整理。
- 每章都要有真实工作挑战、AI 辅助步骤、人工判断步骤和交付物。
- 所有涉及 AI 输出的地方，都要提醒资料脱敏和人工复核。

下一阶段不建议继续扩写正文，而应进入交付版本整理。当前已经新增 `08_出版与交付化/`，用于承接这一阶段：

- 先按版本冻结说明保护三周 21 天主线。
