# 角色使用指南：学员、讲师、组织者

同一套课程资料，需要按角色分开使用。

## 学员怎么用

学员优先阅读：

1. `01_学员主教材/`
2. `02_实操工作簿/`
3. `04_模板与提示词工具包/`

建议路径：

```text
先读本章真实工作挑战 -> 理解方法框架 -> 填写工作簿 -> 用提示词生成第一版 -> 人工修改 -> 保存交付物
```

学员不需要一开始读讲师手册。讲师手册里的课堂话术和控场提示，主要给授课人使用。

## 讲师怎么用

讲师优先阅读：

1. `03_讲师手册/`
2. `05_案例与数据包/`
3. `06_验收与评分系统/`

建议路径：

```text
先看本章教学目标 -> 选择 45/60/90 分钟节奏 -> 演示案例 -> 组织学员实操 -> 用评分标准点评
```

讲师讲课时要少讲工具炫技，多展示“AI 输出后人怎么判断和修改”。

## 组织者怎么用

组织者优先阅读：

1. `00_教材系统说明/`
2. `06_验收与评分系统/`
3. `07_交付版本索引/`

建议路径：

```text
确认课程目标 -> 确认每周成果包 -> 收集学员交付物 -> 用评分标准验收 -> 归档可复用版本
```

组织者重点看成果是否可复核、可复用、可继续迭代，而不是看学员是否使用了某一个固定 AI 工具。

## 共同约定

- 输入 AI 前先脱敏。
- AI 输出后必须人工复核。
- 不把预算、退款、平台合规和客户承诺交给 AI 直接决定。
- 每章至少留下一个能下次继续使用的小成果。
