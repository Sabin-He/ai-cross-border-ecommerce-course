# 文件命名与版本规则

统一命名是为了让学员、讲师和后续 agent 能快速找到材料。

## 教材系统文件命名

| 类型 | 命名方式 | 示例 |
| --- | --- | --- |
| 学员主教材 | `第N周_单元名称.md` | `第2周_岗位AI实战单元.md` |
| 实操工作簿 | `第N周_实操工作簿.md` | `第2周_实操工作簿.md` |
| 讲师手册 | `第N周_讲师手册.md` | `第2周_讲师手册.md` |
| 工具包 | `编号_主题工具包.md` | `03_广告与数据复盘工具包.md` |
| 案例包 | `编号_主题案例包.md` | `04_广告素材与数据复盘案例包.md` |
| 评分标准 | `编号_评分对象.md` | `02_第2周单章交付物评分标准.md` |

## 学员交付物命名

建议格式：

```text
Day编号_交付物名称_姓名或小组_v版本
```

示例：

```text
Day10_广告数据复盘表_张三_v2
Day18_前后版本对比表_第3组_v1
Day21_个人AI落地成果包_李四_v1
```

## 版本规则

| 版本 | 含义 |
| --- | --- |
| v1 | AI 辅助后的第一版，允许粗糙 |
| v2 | 人工复核和修改后的可提交版 |
| v3 | 根据讲师或小组反馈继续优化后的版本 |

## 修改记录规则

每次教材系统有结构性更新，都记录到：

```text
07_交付版本索引/03_更新记录.md
```

记录内容包括：

- 更新日期。
- 修改范围。
- 新增或修改文件。
- 验收结果。
- 下一轮建议。
