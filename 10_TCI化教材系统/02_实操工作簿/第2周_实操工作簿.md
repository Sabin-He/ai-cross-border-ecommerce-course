# Day10 实操：AI 辅助广告数据复盘

## 1. 本章要完成什么

| 项目 | 内容 |
| --- | --- |
| 本章交付物 | 广告数据复盘表 |
| 推荐时间 | 30 到 45 分钟 |
| 需要准备的资料 | 3 到 5 条广告素材或广告活动的脱敏数据 |
| 最终目标 | 写出一版能被自己或团队复用的复盘表 |

资料至少包含：

- 广告对象或素材名称。
- 时间周期。
- 曝光、点击、花费。
- 加购、订单、询盘或销售额中的至少一类转化数据。
- 1 条与素材、页面或评论相关的备注。

## 2. Step by Step

| 步骤 | 你要做什么 | 做到什么程度可以进入下一步 |
| --- | --- | --- |
| 1 | 写清复盘对象 | 能说清是哪一组广告、哪个周期 |

| 3 | 整理核心指标 | 至少有曝光、点击、花费、转化相关字段 |
| 4 | 请 AI 生成复盘初稿 | 得到现象、假设、待确认证据、动作建议 |
| 5 | 人工标注不确定内容 | 把 AI 猜测、缺证据、需业务判断的地方标出来 |
| 6 | 补充人工判断 | 写出素材、页面、库存、价格或受众上的证据 |
| 7 | 修改成第二版 | 删除无证据结论，保留 3 个以内动作 |
| 8 | 保存交付物 | 文件名使用 `Day10_广告数据复盘表_姓名_v2` |

### 提示词 1：把复盘任务说清楚

```text
你是一位耐心、务实的跨境电商广告复盘助手。

我的广告复盘场景是：【平台 / 产品 / 广告对象 / 时间周期】

请帮我把这次复盘任务整理成表格：
1. 真正要回答的问题
2. 需要看的核心指标
3. AI 可以辅助的步骤
4. 必须人工判断的步骤
5. 最后应该留下的交付物

表达要清楚、克制、适合真实工作。
```

### 提示词 2：生成复盘第一版

```text
请基于下面脱敏广告数据，帮我生成一版《广告数据复盘表》初稿。

业务背景：【填写产品、平台、目标用户、广告目标】
数据周期：【填写时间范围】
广告数据：【粘贴脱敏数据】

请按下面结构输出：
1. 每条素材或广告活动的主要现象
2. 可能原因
3. 需要人工确认的证据
4. 下周 3 个以内动作建议

要求：
- 不要编造数据里没有的信息。
- 不要替我做最终预算决定。
- 把猜测和证据分开。
- 所有高风险判断都标出“需要人工确认”。
```

### 提示词 3：检查 AI 初稿

```text
请你像一位严格但温和的广告复盘伙伴，检查下面这份复盘初稿。

我的复盘目标：【填写目标】
复盘初稿：【粘贴 AI 生成内容】

请按下面标准检查：
1. 是否把现象、原因假设、证据和动作分开
2. 是否存在没有证据的判断
3. 是否有需要人工确认的高风险建议
4. 是否出现直接决定预算、停投或承诺效果的表达
5. 下周动作是否控制在 3 个以内

请输出：
- 可以保留的地方：最多 3 点
- 需要修改的地方：最多 3 点
- 我下一步应人工确认的证据：最多 3 条
```

### 提示词 4：沉淀成可复用模板

```text
请帮我把下面这份广告复盘成果整理成可复用模板。

最终复盘内容：【粘贴人工修改后的版本】

请输出：
1. 固定结构
2. 下次需要替换的变量，用【】标出
3. 使用前需要准备的数据字段
4. 使用后必须人工检查的地方
5. 推荐文件命名方式

要求：
- 不增加复杂工具。
- 不写成技术文档。
- 让普通运营或广告同事能直接使用。
```

## 6. 自评表

| 维度 | 好 | 中性 | 需要继续改 | 我的判断 |
| --- | --- | --- | --- | --- |
| 真实问题 | 有明确广告对象和周期 | 问题真实但范围偏大 | 没有明确业务问题 |  |
| 输入资料 | 字段具体且已脱敏 | 数据可用但字段不全 | 数据太少或含敏感信息 |  |
| 指标观察 | 能看到漏斗断点 | 只看到部分现象 | 只盯一个数字 |  |
| 假设与证据 | 猜测和证据分开 | 有假设但证据不足 | 把猜测当结论 |  |
| 人工判断 | 标出需人工确认点 | 有检查但不细 | 直接复制 AI 输出 |  |
| 下一步动作 | 3 个以内且能执行 | 动作可参考但偏泛 | 动作过多或不可执行 |  |
| 复用价值 | 下次能直接改变量复用 | 需要较多调整 | 做完一次就丢掉 |  |

## 7. 提交清单

提交前确认：

- 已写清广告平台、广告对象和数据周期。
- 数据已脱敏。
- 复盘表中有现象、假设、证据和动作。
- AI 猜测已被标出或删除。
- 没有让 AI 直接决定预算。
- 下周动作不超过 3 个。
- 文件名包含 Day10、交付物名称、姓名和版本号。
