# 第 1 章讲师手册：AI 不是神，是减轻重复劳动的助手

## 1. 本章教学目标

让学员建立“AI 可辅助、需复核、有边界”的基本意识，并完成《AI 使用边界清单》。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，10 分钟讲边界，10 分钟案例分类，15 分钟填写，5 分钟点评 |
| 60 分钟 | 5 分钟开场，12 分钟讲边界，15 分钟演示，20 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟讲边界，20 分钟案例讨论，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
今天我们不先追工具，也不讲玄的。先做一件小事：判断哪些工作可以让 AI 帮忙，哪些工作必须由人负责。
```

## 4. 核心讲解要点

- AI 适合整理、分类、起草、归纳。
- 高风险判断不能交给 AI。
- 输入前先脱敏，输出后要复核。
- 从低风险小动作开始。

## 5. 案例演示流程

1. 展示 5 个跨境电商工作动作。
2. 让学员判断风险等级。
3. 用 AI 做初步分类。
4. 人工补充不能上传的资料和检查点。

## 6. 课堂提问

1. 你最想让 AI 帮你做哪件重复事？
2. 这件事出错后会影响谁？
3. 哪些资料不能输入 AI？

## 7. 实操巡视重点

- 是否把账号、订单、客户资料列为可输入。
- 是否只写“可以用 AI”，没有写人工复核。
- 是否选择了过高风险动作作为第一步。

## 8. 点评话术

```text
这个动作可以让 AI 起草，但最终判断还是要你来做。
```

```text
这里要先删掉客户信息，再把内容交给 AI 分类。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 觉得 AI 什么都能做 | 回到风险和责任，区分辅助与决策 |
| 不知道什么算敏感信息 | 举客户、订单、账号、成本、联系方式例子 |
| 想选复杂任务 | 先选低风险重复动作 |

## 10. 课后提醒

提交 `Day01_AI使用边界清单_姓名_v1`。提醒学员后续所有提示词都要先看这张边界清单。

# 第 2 章讲师手册：学会把问题说清楚

## 1. 本章教学目标

让学员把模糊需求改成清楚的六段式提示词，并完成《个人提示词模板 v1》。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，10 分钟讲六段式，10 分钟对比演示，15 分钟改写，5 分钟点评 |
| 60 分钟 | 5 分钟开场，12 分钟讲结构，15 分钟演示，20 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟拆提示词，20 分钟对比输出，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
AI 没有读心术。你给它一个模糊任务，它只能猜；你给它清楚交接，它才更容易做出可用初稿。
```

## 4. 核心讲解要点

- 提示词是任务交接单。
- 背景、任务、约束和输出格式都要写。
- 一次只解决一个具体问题。
- 要求 AI 标出待人工确认内容。

## 5. 案例演示流程

1. 展示“帮我写 Listing”。
2. 按角色、背景、任务、资料、约束、输出补全。
3. 对比改写前后的输出差异。
4. 保存为个人提示词模板。

## 6. 课堂提问

1. 这条提示词缺少什么背景？
2. 这次任务是不是太大？
3. 输出应该用表格、清单还是文案？

## 7. 实操巡视重点

- 是否把多个任务塞进一条提示词。
- 是否缺少输出格式。
- 是否没有写“不要编造”和“需要人工确认”。

## 8. 点评话术

```text
这条提示词已经有任务了，但还缺少约束。要写清不要编造、不要夸大。
```

```text
这里可以加一句“请标出需要人工确认的地方”，输出会更安全。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 提示词太长 | 保留背景、任务、资料、约束、输出 |
| 输出仍然空泛 | 补充样例、限制和业务资料 |
| 不会写角色 | 用“跨境电商运营助理”等工作型角色 |

## 10. 课后提醒

提交 `Day02_个人提示词模板_姓名_v1`。提醒学员以后每次复制提示词前先替换【】变量。

# 第 3 章讲师手册：AI 辅助产品理解

## 1. 本章教学目标

让学员把产品参数整理成“用户、场景、痛点、证据、卖点”的产品理解卡。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，10 分钟讲产品卡，10 分钟演示，15 分钟填写，5 分钟点评 |
| 60 分钟 | 5 分钟开场，12 分钟讲概念，15 分钟演示，20 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟讲证据，20 分钟案例，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
参数不等于卖点。我们要先看清产品帮谁、在什么场景里解决什么问题，再让 AI 帮忙表达。
```

## 4. 核心讲解要点

- 产品事实要可验证。
- 目标用户不能写成所有人。
- 卖点要同时回应痛点和事实。
- 认证、数据、效果必须人工确认。

## 5. 案例演示流程

1. 展示一组产品参数。
2. 用 AI 整理产品理解卡。
3. 标出无证据卖点。
4. 人工修改成可用版本。

## 6. 课堂提问

1. 这个产品最适合谁？
2. 哪个卖点有事实支撑？
3. 哪句话需要人工确认？

## 7. 实操巡视重点

- 是否把目标用户写得过宽。
- 是否把参数直接当卖点。
- 是否出现无证据效果表达。

## 8. 点评话术

```text
这个卖点听起来不错，但还没有对应产品事实，需要补证据。
```

```text
目标用户可以再具体一点，不要写成所有家庭用户。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 产品资料太少 | 先用现有参数做第一版，缺口标待确认 |
| 卖点太泛 | 回到具体场景和痛点 |
| AI 生成夸张词 | 删掉并改成事实表达 |

## 10. 课后提醒

提交 `Day03_产品理解卡_姓名_v1`。提醒学员 Day05 生成 Listing 时要引用这张卡。

# 第 4 章讲师手册：AI 辅助竞品和评论分析

## 1. 本章教学目标

让学员从评论里提炼用户证据，并完成《竞品评论分析表》。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，8 分钟讲证据，12 分钟演示，15 分钟实操，5 分钟点评 |
| 60 分钟 | 5 分钟开场，12 分钟讲分类，15 分钟演示，20 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟讲样本选择，20 分钟演示，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
评论区像用户访谈室。AI 可以先帮我们分门别类，但结论必须回到用户原话。
```

## 4. 核心讲解要点

- 好评和差评都要看。
- 结论要保留原文证据。
- 不把个别评论夸大成普遍问题。
- 学习用户需求，不照抄竞品表达。

## 5. 案例演示流程

1. 展示 8 到 10 条评论样例。
2. 用 AI 分类。
3. 标出每类原文证据。
4. 把结论转成卖点、避坑或 FAQ。

## 6. 课堂提问

1. 哪条评论最能说明用户痛点？
2. 这个结论有没有原文证据？
3. 这条反馈可以转成什么动作？

## 7. 实操巡视重点

- 是否缺评论原文。
- 是否把少数评论当普遍趋势。
- 是否照抄竞品表达。

## 8. 点评话术

```text
这个结论需要补原文证据，否则只是我们的推测。
```

```text
这里不是复制竞品表达，而是提炼用户真正关心的问题。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 评论样本太少 | 先练格式，课后补样本 |
| AI 总结太泛 | 要求保留原文和分类依据 |
| 只看好评 | 加入差评和中性评论 |

## 10. 课后提醒

提交 `Day04_竞品评论分析表_姓名_v1`。提醒学员 Day05 使用评论证据，不直接套文案。

# 第 5 章讲师手册：AI 辅助 Listing 初稿

## 1. 本章教学目标

让学员基于产品理解卡和评论分析表生成 Listing v1，并标出风险词和待确认信息。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，8 分钟讲输入资料，12 分钟演示，15 分钟生成，5 分钟点评 |
| 60 分钟 | 5 分钟开场，10 分钟讲结构，15 分钟演示，22 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟讲标题/五点/描述，20 分钟演示，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
这一章不追求一次写到完美。我们先搭一个可修改的脚手架，下一章再训练判断和修改。
```

## 4. 核心讲解要点

- Listing 初稿必须基于产品卡和评论证据。
- 标题、五点、描述分开生成。
- 关键词自然融入，不堆砌。
- 初稿必须列出风险词和待确认信息。

## 5. 案例演示流程

1. 展示产品理解卡和评论分析表。
2. 让 AI 生成标题和五点。
3. 标出无证据表达。
4. 保存 v1，不在本章追求终稿。

## 6. 课堂提问

1. 这条卖点来自哪个产品事实？
2. 哪个词可能夸大？
3. 哪些内容要留到下一章修改？

## 7. 实操巡视重点

- 是否没有引用产品卡和评论表。
- 是否出现无证据效果承诺。
- 是否把关键词堆砌进标题。

## 8. 点评话术

```text
这一版可以作为初稿，但不能直接发布。下一步要做事实和规则审核。
```

```text
这个关键词放得有点硬，可以先保证自然可读。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 想直接发终稿 | 强调这是 v1，下一章修改 |
| 文案太夸张 | 回到事实证据 |
| 结构混乱 | 分标题、五点、描述分别生成 |

## 10. 课后提醒

提交 `Day05_Listing初稿_姓名_v1`。提醒学员保留待确认项，Day06 用来修改。

# 第 6 章讲师手册：修改比生成更重要

## 1. 本章教学目标

让学员把 AI 初稿改成经过人工判断的 Listing v2，并留下审核记录。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，10 分钟讲四审，10 分钟演示，15 分钟修改，5 分钟点评 |
| 60 分钟 | 5 分钟开场，12 分钟讲事实/规则/用户/品牌审，15 分钟演示，20 分钟实操，8 分钟点评 |
| 90 分钟 | 8 分钟开场，15 分钟讲审核标准，20 分钟演示，32 分钟实操，10 分钟互评，5 分钟提醒 |

## 3. 开场引导话术

```text
真正决定质量的，不是 AI 第一次写得多漂亮，而是我们能不能发现问题、判断取舍、改成可用版本。
```

## 4. 核心讲解要点

- 先核事实，再润色语言。
- 平台规则和效果承诺要谨慎。
- AI 的修改建议也要由人判断。
- 保留 v1、修改理由和 v2。

## 5. 案例演示流程

1. 展示一条有风险的 Listing 初稿。
2. 按事实审、规则审、用户审、品牌审标注。
3. 用 AI 提修改建议。
4. 人工决定采用或拒绝。

## 6. 课堂提问

1. 这里是事实问题、规则问题还是语气问题？
2. 哪个表达需要产品资料证明？
3. 这条 AI 建议你会不会采用？

## 7. 实操巡视重点

- 是否只润色语言，没有查事实。
- 是否保留 v1 和修改理由。
- 是否把 AI 修改建议全部采纳。

## 8. 点评话术

```text
这次修改不是只让句子更顺，而是把无证据表达改成了可验证表达。
```

```text
这里保留 v1 和修改理由很重要，下次你会更快判断类似问题。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 不知道怎么审 | 按事实、规则、用户、品牌四步看 |
| 只改措辞 | 追问修改理由和证据 |
| 害怕删 AI 内容 | 强调删掉不确定内容是质量动作 |

## 10. 课后提醒

提交 `Day06_Listing修改稿_姓名_v2`。提醒学员附上 2 到 3 条修改理由。

# 第 7 章讲师手册：第 1 周复盘，建立个人 AI 基础提效包

## 1. 本章教学目标

让学员把第 1 周交付物整理成个人基础工具箱，并衔接第 2 周岗位实战。

## 2. 建议时间安排

| 版本 | 节奏 |
| --- | --- |
| 45 分钟 | 5 分钟开场，8 分钟讲成果包，12 分钟整理，15 分钟展示，5 分钟提醒 |
| 60 分钟 | 5 分钟开场，10 分钟讲结构，20 分钟整理，20 分钟点评，5 分钟提醒 |
| 90 分钟 | 8 分钟开场，12 分钟讲结构，30 分钟整理，30 分钟展示互评，10 分钟衔接第 2 周 |

## 3. 开场引导话术

```text
如果文件散在聊天记录里，下周还是用不起来。今天不是多学一个技巧，而是把本周成果整理成能继续使用的工具箱。
```

## 4. 核心讲解要点

- 复盘不是写感想，而是整理交付物。
- 每个文件要有用途说明。
- 保留 v1/v2 和修改理由。
- 第 1 周成果包要连接第 2 周岗位场景。

## 5. 案例演示流程

1. 展示基础提效包首页。
2. 放入边界清单、提示词、产品卡、评论表、Listing v1/v2。
3. 为每个文件写一句用途说明。
4. 选择第 2 周岗位场景。

## 6. 课堂提问

1. 你下周最可能复用哪个文件？
2. 哪个文件还需要补人工检查点？
3. 第 2 周你想把 AI 放进哪个岗位动作？

## 7. 实操巡视重点

- 是否只是打包文件，没有用途说明。
- 是否缺少 v1/v2 对比。
- 是否没有衔接第 2 周岗位场景。

## 8. 点评话术

```text
这个成果包已经有文件了，下一步要补使用顺序，让下周能直接打开用。
```

```text
这里可以写清第 2 周场景，比如“用评论分析表支持广告素材方向”，会比“继续用 AI”更具体。
```

## 9. 常见卡点

| 卡点 | 回应方式 |
| --- | --- |
| 文件散乱 | 先做首页索引 |
| 只写心得 | 回到交付物证据 |
| 不知道下周怎么用 | 选择一个岗位重复动作 |

## 10. 课后提醒

提交 `Day07_个人AI基础提效包_姓名_v1`。提醒学员第 2 周开始会把这些能力放进岗位流程。
