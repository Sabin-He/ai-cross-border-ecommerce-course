# 课堂常见问题与回应话术

本文件给讲师和助教使用。回应原则是温和、具体、可执行，不制造焦虑，不夸大 AI。

## 一、AI 使用边界

| 学员问题 | 回应话术 |
| --- | --- |
| “是不是以后这些工作都能让 AI 自动做？” | “AI 可以帮我们整理、起草和检查，但最终判断仍然要由人负责。课程里我们只做可复核的小动作。” |
| “我可以直接上传客户聊天记录吗？” | “不建议。先删除客户姓名、订单号、邮箱、电话和账号信息，再让 AI 帮你分类或起草。” |
| “AI 写得很完整，能不能直接用？” | “先当成 v1。你还要核对事实、平台规则、语气和业务边界，再决定哪些内容能用。” |

## 二、学员卡住时

| 场景 | 回应话术 |
| --- | --- |
| 不知道选哪个项目 | “先选资料最齐、风险最低、一周内能交付一个文件的项目。价值高但做不完的项目先放到下一轮。” |
| 提示词写不出来 | “先不要追求完整提示词。写清背景、任务、资料、输出格式和不要做什么，就能开始。” |
| AI 输出太空 | “通常是输入资料不够具体。补充业务背景、样例、限制和输出格式，再让 AI 重做一版。” |
| 不知道怎么改 AI 初稿 | “先查事实，再看规则，再看用户是否能读懂，最后才润色语言。” |

## 三、作业退回

| 问题 | 回应话术 |
| --- | --- |
| 项目范围太大 | “这个方向有价值，但一周内不容易闭环。建议先缩成一个模板、一张表或一个 SOP。” |
| 没有人工修改 | “目前看起来像 AI 初稿。请补 2 到 3 处你人工修改的地方，并说明为什么改。” |
| 缺少证据 | “这个判断需要回到资料。请补评论、数据、客服记录或旧文件里的证据。” |
| 文件散乱 | “先做一个首页索引。写清每个文件的用途和使用顺序，成果包会更容易验收。” |

## 四、课堂节奏

| 情况 | 回应话术 |
| --- | --- |
| 学员想继续扩展 | “先完成今天的交付物。扩展想法可以记到‘下一轮’里，不要影响本周闭环。” |
| 学员担心跟不上 | “先做简单版。今天只要留下一个可修改文件，后面还能继续迭代。” |
| 学员只想看演示 | “演示只是给你看路径。真正有用的是你把自己的脱敏资料放进去，做出自己的版本。” |
| 学员互评太泛 | “请给对方一个具体建议：哪里清楚、哪里需要证据、下一步改哪一处。” |

## 五、敏感与合规提醒

- 不上传客户隐私、订单、账号密码、内部成本、供应商报价或广告账户截图。
- 不让 AI 承诺退款、补偿、投放结果或平台规则结论。
- 涉及价格、库存、政策、预算和客户争议时，必须人工确认。
- 对外分享成果包时，只展示脱敏样例和可验证变化。
