# 广告与数据复盘工具包

本工具包当前先整理第 10 章《AI 辅助广告数据复盘》的可复用模板和提示词。

## 1. 适用场景

适合这些工作：

- 复盘 3 到 5 条广告素材。
- 比较广告活动表现。
- 观察点击高但转化低的问题。
- 整理下周广告优化动作。

不适合直接做这些事：

- 让 AI 决定预算。
- 让 AI 判断平台合规风险。
- 让 AI 承诺投放效果。

## 2. 使用前准备

准备脱敏数据：

| 字段 | 说明 |
| --- | --- |
| 广告对象 | 素材、广告组或活动名称，可用 A/B/C 代替 |
| 时间周期 | 例如 2026-04-01 至 2026-04-07 |
| 曝光 | 展示次数 |
| 点击 | 点击次数 |
| 花费 | 广告花费，可用模拟值或脱敏值 |
| 转化 | 加购、询盘、订单或销售额 |
| 备注 | 素材方向、页面情况、评论反馈等 |

不要放入：

- 真实账户名。
- 客户姓名、邮箱、订单号。
- 内部成本、利润、未公开价格策略。
- 广告后台完整截图。

## 3. 复盘表模板

| 指标或素材 | 本期数据 | 观察结果 | 可能原因 | 证据或待确认项 | 下一步动作 |
| --- | --- | --- | --- | --- | --- |
| 【素材 A】 | 【填写数据】 | 【填写现象】 | 【填写假设】 | 【填写证据或待确认】 | 【填写动作】 |
| 【素材 B】 | 【填写数据】 | 【填写现象】 | 【填写假设】 | 【填写证据或待确认】 | 【填写动作】 |
| 【素材 C】 | 【填写数据】 | 【填写现象】 | 【填写假设】 | 【填写证据或待确认】 | 【填写动作】 |

## 4. 通用提示词

```text
你是一位务实的跨境电商广告复盘助手。

请基于下面脱敏广告数据，帮我整理一版复盘初稿。

业务背景：【产品 / 平台 / 目标用户 / 广告目标】
数据周期：【时间范围】
广告数据：【粘贴脱敏数据】

请按“现象 / 可能原因 / 需要人工确认的证据 / 下一步动作”输出。

要求：
1. 不要编造数据里没有的信息。
2. 不要替我做最终预算决定。
3. 把猜测和证据分开。
4. 下周动作不超过 3 个。
5. 语言清楚、克制、适合真实工作复盘。
```

## 5. 人工检查清单

使用 AI 输出后，逐项检查：

- 数据周期是否清楚。
- 数据是否脱敏。
- 是否只看一个指标。
- 是否把猜测当成结论。
- 是否缺少素材、页面、库存、价格或受众证据。
- 是否让 AI 直接决定预算。
- 下周动作是否超过 3 个。

## 6. 推荐文件名

```text
Day10_广告数据复盘表_姓名_v2
```

团队复用时可以改成：

```text
广告复盘模板_平台_产品线_v1
```

# 广告素材方向工具

## 1. 适用场景

适合在投放前整理素材测试方向，尤其适合：

- 不知道先测哪几个素材方向。
- 素材创意很多，但缺少测试假设。
- 想把评论痛点转成广告钩子和证明点。

## 2. 素材方向表模板

| --- | --- | --- | --- | --- | --- | --- | --- |
| 【方向 1】 |  |  |  |  |  |  |  |
| 【方向 2】 |  |  |  |  |  |  |  |
| 【方向 3】 |  |  |  |  |  |  |  |

## 3. 素材方向提示词

```text
请基于下面产品资料和用户痛点，生成 3 个广告素材方向。

产品资料：【填写】
目标用户：【填写】
用户痛点：【粘贴评论、客服反馈或产品理解卡】

每个方向请包含：
目标人群、痛点、前 3 秒钩子、使用场景、证明点、测试假设、需要人工确认的地方。

要求：
- 一个方向只验证一个主要假设。
- 不要夸大承诺。
- 证明点必须真实可展示。
- 不要直接照抄竞品素材。
```

## 4. 人工检查清单

- 痛点是否来自真实资料。
- 钩子是否夸张或虚假。
- 证明点是否能拍出来。
- 素材方向是否能在投放后复盘。
- 是否一个方向只验证一个主要假设。
