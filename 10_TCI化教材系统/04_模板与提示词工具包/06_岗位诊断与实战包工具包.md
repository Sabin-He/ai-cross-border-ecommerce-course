## 2. 岗位诊断提示词

```text
请基于我的岗位工作记录，帮我整理一张岗位提效诊断表。

我的岗位是：【填写】
我的工作动作是：【列出最近一天或一周真实动作】

请按“动作 / 频率 / 风险 / 输入资料 / 输出结果 / AI 可辅助步骤 / 人工检查点 / 是否适合试点”输出。

要求：
- 写具体动作，不写职责口号。
- 高风险动作要提醒人工复核。
- 推荐 1 个最适合先试点的小动作。
```

## 4. 岗位包整理提示词

```text
请帮我把下面这些岗位材料整理成一个岗位 AI 实战包目录。

岗位：【填写】
已有材料：【列出 Day08 到 Day13 的交付物】

请输出：
1. 岗位包首页目录
2. 每个文件什么时候用
3. 推荐使用顺序
4. 缺少哪些材料
5. 第 3 周适合落地的真实项目建议

要求：
- 不要把所有文件都塞进去。
- 只保留会再次使用的材料。
- 标出每个文件的人工检查点。
```

## 5. 人工检查清单

- 是否只保留会再次使用的文件。
- 每个文件是否有使用场景。
- 每个文件是否写清输入资料。
- 是否至少有一个 SOP。
- 是否有反馈或评分标准。
- 是否能衔接第 3 周真实项目。
