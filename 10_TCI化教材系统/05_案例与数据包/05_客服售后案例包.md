# 客服售后案例包

本案例包用于第 11 章《AI 辅助客服和售后回复》。

## 1. 案例：物流延迟投诉

### 业务背景

独立站客户反馈包裹延迟，语气比较着急。客服需要安抚客户、说明查询路径，但不能承诺政策之外的补偿。

### 脱敏输入资料

客户问题：

```text
我的包裹已经晚了 5 天，你们到底什么时候送到？如果再不到我就要投诉。
```

可用背景：

- 物流状态：已到本地配送中心。
- 预计更新：2 到 3 天内可能更新。
- 店铺政策：可协助查询，暂不能直接承诺赔偿。

## 2. AI 初稿样例

```text
非常抱歉给您带来不便。我们会马上为您催促物流，如果 2 天内没有送到，我们会给您退款。
```

这版问题：

- “会给您退款”超出当前政策。
- 没有说明需要继续查询。
- 没有标出人工确认。

## 3. 人工修改后样例

```text
很抱歉让您等了这么久，我能理解您现在会着急。

我这边看到包裹目前已到本地配送中心，通常接下来会进入末端派送。为了避免给您不准确的信息，我会先为您再次查询物流更新，并在有新状态后尽快告知您。

如果后续物流长时间没有更新，我们会按照店铺售后政策继续协助处理。这里涉及具体订单状态，我会先人工确认后再给您下一步方案。
```

## 4. 评价标准

| 维度 | 达标表现 |
| --- | --- |
| 情绪 | 先回应客户着急 |
| 事实 | 只说明已确认的物流状态 |
| 规则 | 不承诺政策外补偿 |
| 方案 | 给出查询和后续处理路径 |
| 安全 | 不出现客户隐私 |
