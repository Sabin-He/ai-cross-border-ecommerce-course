# 运营周报与 SOP 案例包

本案例包用于第 12 章《AI 辅助运营周报》和第 13 章《把一个动作变成 SOP》。

## 1. 运营周报案例

### 业务背景

某 Amazon 店铺本周销售额下降，但广告点击上升，库存接近预警。运营需要写一页周报给团队。

### 脱敏输入资料

| 指标 | 上周 | 本周 | 变化 |
| --- | ---: | ---: | ---: |
| 销售额 | 12000 | 9800 | -18% |
| 订单量 | 240 | 196 | -18% |
| 转化率 | 8.0% | 6.2% | -1.8pp |
| 广告点击 | 1800 | 2300 | +28% |
| 库存天数 | 18 | 9 | -9 天 |

关键事件：

- 本周广告素材更换为痛点开头。
- 主推 SKU 库存接近预警。
- 两条新差评提到包装问题。

### 人工修改后周报样例

| 模块 | 内容 |
| --- | --- |
| 核心变化 | 销售额和订单量下降 18%，广告点击增加但转化率下降 |
| 可能原因 | 流量质量变化、库存接近预警、包装差评可能影响购买信心 |
| 待确认项 | 检查主推 SKU 是否影响购物车、查看新素材点击后页面停留、复核差评内容 |
| 下周动作 | 1. 检查库存和购物车状态；2. 复盘新素材流量质量；3. 汇总包装差评并反馈供应链 |
| 风险提醒 | 库存只剩 9 天，需优先处理补货或广告节奏 |

## 2. SOP 案例：广告数据复盘 SOP

### SOP 初稿问题

```text
每周看广告数据，找出表现不好的广告，优化素材。
```

问题：

- 没有输入资料。
- 没有具体步骤。
- 没有检查标准。
- 没有异常处理。

### 人工修改后 SOP 样例

| 模块 | 内容 |
| --- | --- |
| SOP 名称 | 每周广告数据复盘 SOP |
| 适用场景 | 每周复盘 3 到 5 条广告素材表现 |
| 输入资料 | 过去 7 天曝光、点击、花费、加购、订单、销售额、素材方向 |
| 操作步骤 | 导出数据 -> 检查字段 -> 标出异常 -> 用 AI 整理初稿 -> 人工补证据 -> 写下周动作 |
| 输出结果 | 广告数据复盘表 v2 |
| 检查标准 | 有周期、有异常、有证据、有 3 个以内动作 |
| 异常处理 | 数据缺字段时暂停；涉及预算调整时找负责人确认；AI 编造原因时删除 |

## 3. 课堂讨论点

- 哪些内容是事实，哪些只是原因假设？
- 哪个动作可以写得更具体？
- 这个 SOP 新人能不能照着做？
