# 岗位诊断与实战包案例包

本案例包用于第 8 章《从“会用 AI”到“用 AI 做工作》和第 14 章《建立岗位 AI 实战包》。

## 1. 岗位诊断案例

### 业务背景

一位广告运营每周要做素材方向、广告复盘、竞品观察、周报和跨部门沟通。她想知道哪一步最适合先用 AI 辅助。

### 工作动作记录

| 动作 | 频率 | 风险 | 当前问题 |
| --- | --- | --- | --- |
| 整理竞品广告截图 | 每周 | 低 | 分类慢 |
| 生成素材方向 | 每周 | 中 | 思路容易散 |
| 检查广告异常 | 每天 | 中 | 指标太多 |
| 决定预算调整 | 每周 | 高 | 涉及业务风险 |
| 写广告周报 | 每周 | 中 | 经常写成流水账 |

### 诊断结果样例

| 动作 | AI 可辅助步骤 | 人工检查点 | 是否适合试点 |
| --- | --- | --- | --- |
| 整理竞品广告截图 | 分类、提取钩子、整理方向 | 是否误解素材卖点 | 适合 |
| 生成素材方向 | 扩展方向和钩子 | 是否夸大、是否可拍 | 适合 |
| 检查广告异常 | 整理异常和假设 | 是否有业务证据 | 适合 |
| 决定预算调整 | 整理参考信息 | 预算必须人工决定 | 不适合作为第一试点 |
| 写广告周报 | 生成结构化初稿 | 原因和动作需人工确认 | 适合 |

## 2. 岗位 AI 实战包案例

### 广告岗位包首页样例

| 模块 | 内容 |
| --- | --- |
| 岗位包名称 | 广告岗位 AI 实战包 |
| 服务场景 | 每周素材方向、广告复盘和周报整理 |
| 主要问题 | 素材方向散、复盘不稳定、周报偏流水账 |
| 推荐使用顺序 | 素材方向表 -> 广告数据复盘表 -> 广告复盘 SOP -> 周报模板 |
| 包含文件 | 广告素材方向表、广告数据复盘表、广告复盘 SOP、单章评分标准 |
| 人工检查点 | 素材证明点、预算动作、数据周期、原因证据 |
| 第 3 周候选项目 | 建立一套“广告素材测试与复盘”小流程 |

## 3. 评价标准

| 维度 | 达标表现 |
| --- | --- |
| 诊断 | 能选出低风险试点动作 |
| 工具 | 至少 3 个可复用文件 |
| 流程 | 有一个 SOP 或使用顺序 |
| 反馈 | 有评分或复盘标准 |
| 衔接 | 能自然进入第 3 周真实项目 |
