# 个人基础提效包案例包

本案例包用于第 7 章《建立个人 AI 基础提效包》。

## 1. 业务背景

一位运营完成了第 1 周练习，但文件散在聊天记录、表格和下载目录里。现在需要整理成下周还能继续使用的个人基础提效包。

## 2. 文件清单

| 文件 | 当前问题 |
| --- | --- |
| AI 使用边界清单 | 有内容，但没有版本号 |
| 个人提示词模板 | 可用，但没有写适用场景 |
| 产品理解卡 | 内容完整 |
| 竞品评论分析表 | 缺少原文证据列 |
| Listing 初稿 v1 | 有风险词 |
| Listing 修改稿 v2 | 有修改理由 |
| Listing 审核清单 | 可复用 |

## 3. 整理后首页样例

| 模块 | 内容 |
| --- | --- |
| 成果包名称 | 个人 AI 基础提效包 |
| 本周解决的问题 | 从“临时问 AI”变成有边界、有模板、有证据地使用 AI |
| 推荐使用顺序 | 边界清单 -> 提示词模板 -> 产品理解卡 -> 评论分析表 -> Listing v1 -> 审核清单 -> Listing v2 |
| 最常用提示词 | 六段式提示词模板 |
| 需要补强 | 评论分析表补原文证据 |
| 第 2 周岗位场景 | 广告素材方向和客服 FAQ |

## 4. 评价标准

| 维度 | 达标表现 |
| --- | --- |
| 完整性 | 至少 5 个交付物 |
| 可查找 | 有首页索引 |
| 可复用 | 每个文件有用途说明 |
| 可复核 | 有人工检查点 |
| 可衔接 | 能进入第 2 周岗位场景 |
