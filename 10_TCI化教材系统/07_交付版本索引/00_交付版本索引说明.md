# 交付版本索引说明

本目录回答一个问题：**现在可以把哪个版本发出去，发给谁。**

课程资料会持续修订。如果没有版本索引，组织者每次分享前都要重新判断"这份文件是不是最新的、能不能外发"。本目录把这件事固定下来。

## 本目录包含什么

| 文件 | 用途 |
| --- | --- |
| `01_可分享版本清单.md` | 可以直接发给学员和外部对象的文件清单 |
| `02_内部版本清单.md` | 只在讲师、助教、组织者内部流转的材料 |
| `03_更新记录.md` | 每轮结构性修订的记录 |

## 两类版本怎么区分

- **可分享版本**：内容已验收、不含内部工作痕迹，发出去不需要再解释。目前就是两个单文件 HTML 阅读包。
- **内部版本**：源章节、派生视图、评分系统、试讲记录等工作材料。通过 Git 仓库管理，不单独打包外发。

## 什么时候更新本目录

1. 每次重新生成阅读包 HTML 后，更新 `01_可分享版本清单.md` 的版本号和日期。
2. 每轮试讲修订结束后，按 [`../09_试讲与修订/00_试讲与修订说明.md`](../09_试讲与修订/00_试讲与修订说明.md) 的流程，在 `03_更新记录.md` 追加一条记录。
3. 课程进入新的阶段版本（如 v0.6 → v1.0）时，三个文件一起核对。
