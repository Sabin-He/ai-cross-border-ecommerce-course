# 内部版本清单

内部材料统一用 Git 仓库管理版本，不单独打包。本清单说明哪些目录属于内部工作层，以及它们之间的派生关系。

## 内部材料分层

| 层 | 目录 | 性质 |
| --- | --- | --- |
| 唯一真源（SoT） | `01_第1周_AI基础提效周/`、`02_第2周_AI岗位实战周/`、`03_第3周_AI落地陪跑周/` | 概念、方法、案例、误区的唯一出处 |
| 派生视图 | `09_章节实操手册/`、`10_TCI化教材系统/01_学员主教材/`、`02_实操工作簿/`、`03_讲师手册/` | 从源章节派生，改动必须先改源 |
| 独立维护 | `04_模板库/`、`05_提示词库/`、`06_评分与反馈/`、`10_TCI化教材系统/04_~06_` | 模板、提示词、评分各自单源 |
| 过程记录 | `10_TCI化教材系统/09_试讲与修订/`、`07_交付版本索引/` | 试讲反馈与版本记录 |
| 构建工具 | `tools/` | 阅读包构建与迁移脚本 |

派生规则详见 [`../../00_课程总纲/11_单源一致性约定.md`](../../00_课程总纲/11_单源一致性约定.md)。
