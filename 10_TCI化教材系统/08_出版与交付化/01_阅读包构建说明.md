# 阅读包构建说明

两个对外分享的单文件 HTML 不是手写的，由构建脚本从 Markdown 源文件统一生成。本说明回答三个问题：怎么生成、收录了什么、改了内容之后要做什么。

## 一、怎么生成

在仓库根目录执行：

```text
python tools/build_reading_packages.py
```

要求 Python 3.9 以上，只用标准库，不需要安装任何依赖，也不需要联网。

脚本一次写出 4 个文件：

| 输出 | 说明 |
| --- | --- |
| `AI跨境电商效能提升实战课_书籍阅读版.html` | 对外分享主文件 |
| `book_reading_package/index.html` | 书籍版的内部预览副本，内容相同 |
| `AI跨境电商效能提升实战课_资料库阅读器.html` | 讲师 / 协作者用，含全部 Markdown |
| `html_reading_package/index.html` | 阅读器的内部预览副本，内容相同 |

脚本结尾自带自检（附录正文、实操手册锚点、关键文档是否在产物里），输出 `FAIL` 时不要分享该次产物。

## 二、书籍阅读版收录什么

按阅读顺序分组：

1. **课程导读**：课程总纲中面向学员的 9 份文档（含《课程通用约定》）。
2. **三周正文**：第 1 至 21 章源章节。
3. **章节实操手册**：Day01 至 Day21，章节正文里的"配套实操手册"链接可直接跳转。
4. **AI Agent Skills**：编写入门教程。
5. **附录**：附录章节说明、附录 A（预算）、附录 B（Agent 与工作流）、附录 C（合规）、三个库使用说明。

资料库阅读器则收录仓库内全部 Markdown 文件（不含 `tools/`、输出目录和仓库配置）。

## 三、构建时做了什么处理

- **Mermaid 转内嵌 SVG**：`flowchart / graph TD|LR` 流程图在构建时渲染成 SVG 内嵌，打开 HTML 不依赖 Mermaid 和外部 CDN。注意：渲染器只支持本库使用的简单语法（`A[标签] --> B[标签]`），不支持边标签、子图、虚线；新增图示请保持同样的写法。
- **图片内嵌**：Markdown 引用的本地 png / svg 转成 base64 内嵌，单文件即可离线查看。
- **库内链接改写**：指向库内 `.md` 的链接，目标被收录时改写为页内锚点；未收录时退化为纯文本，避免单文件场景出现死链。

## 四、改了内容之后要做什么

1. 按单源一致性约定改完 Markdown。
2. 重新跑一遍构建脚本。
3. 按 [`../../分享说明.md`](../../分享说明.md) 的 5 步检查验收书籍阅读版。
4. 更新 [`../07_交付版本索引/01_可分享版本清单.md`](../07_交付版本索引/01_可分享版本清单.md) 的版本号和日期，并在 [`../07_交付版本索引/03_更新记录.md`](../07_交付版本索引/03_更新记录.md) 追加记录。

## 五、调整收录范围

书籍阅读版的收录清单在脚本的 `book_manifest()` 函数里，按组维护文件路径；新增章节或附录时改这一处即可。资料库阅读器自动扫描全库 Markdown，无需维护清单。
