## 优先级判断

| 优先级 | 判断标准 |
| --- | --- |
| P0 | 影响学员完成交付物，或涉及敏感信息、错误承诺、平台规则风险 |
| P1 | 影响课堂节奏、讲师讲解效率或作业验收效率 |
| P2 | 表达优化、标题调整、示例补充、阅读体验提升 |

## 修改位置建议

| 问题类型 | 优先修改位置 |
| --- | --- |
| 概念、方法、案例、误区 | 源章节，再同步派生视图 |
| Step by Step、工作纸、提示词 | `09_章节实操手册/` 或 `02_实操工作簿/` |
| 课堂时间、话术、提问、点评 | `03_讲师手册/` |
| 模板字段、交付物格式 | `04_模板库/` |
| 提示词变量、输出格式 | `05_提示词库/` |
| 收作业和退回标准 | `21天交付物检查清单.md` |

- [ ] Markdown 内部链接检查通过。
- [ ] 更新记录已补充。
