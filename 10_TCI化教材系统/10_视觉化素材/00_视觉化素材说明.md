# 视觉化素材说明

本目录存放课程阅读版使用的视觉素材。核心知识图表优先使用 SVG，因为它们文字可控、可内嵌到单文件 HTML、便于后续修改；封面和开场氛围图可以使用 PNG 位图。

## 使用原则

- 图示只服务理解，不做装饰堆叠。
- 每张图对应一个课程关键结构：路径、边界、流程、矩阵或闭环。
- 图中文字保持简短，详细解释仍放在正文和表格里。
- AI 生成位图只用于封面、场景氛围图或章节开场，不替代需要精确文字的核心图表。
- 位图中不放课程标题、章节标题或知识点文字，文字由 Markdown 标题和图注承担。

## 图表使用建议

| 图表类型 | 学员先看什么 | 讲师使用方式 |
| --- | --- | --- |
| 路径图 | 先看自己处在哪一周、最终要留下什么 | 用于开课和每周复盘 |
| 热力图 | 先判断场景风险和可检查性 | 用于纠正“什么都交给 AI”的误用 |
| 雷达图 | 先看提示词缺哪一维 | 用于点评学员提示词 |
| 气泡图 | 先选小而真实的项目 | 用于第 3 周项目收敛 |
| 结构图 | 先看成果包证据是否完整 | 用于结营前验收 |
| 前后对比图 | 先看输入、AI 初稿、人工修改、交付物的关系 | 用于关键实操日示范 |
| 封面和开场图 | 先建立课程场景感 | 用于进入课程或每周单元前 |
