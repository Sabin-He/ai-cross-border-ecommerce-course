# 附录 A：AI 预算与成本意识

> 本附录不在 21 章主线内，作为**可选深度阅读**。建议在第 1 周结束、开始大量调用 AI 之前读一遍；或在第 3 周项目落地阶段，发现"AI 调用费用比预想高"时回看。
>
> **本附录想解决的问题**：很多团队在用 AI 半年后才发现，月度账单已经远超预期；或反过来——舍不得用付费模型，结果质量长期上不去。两者都是"没有成本意识"。

---

## 一、为什么要专门讲成本

跨境电商团队和"AI 中度依赖者"最容易踩两个极端：

| 极端 | 表现 | 成因 |
| --- | --- | --- |
| **乱花钱** | 月度账单从 $50 跳到 $800，老板才发现 | 没设预算上限、没人盯、模型默认贵 |
| **死省钱** | 一直用免费版，效果差，反复返工 | 把 AI 看成"工具费"而不是"人时省下来的钱" |

正确的状态是：**知道每一类任务该用什么模型、该花多少、什么时候该升级**。这一节不是 finance 课，是给运营/老板看的"AI 账本认知"。

---

## 二、核心概念

| 概念 | 大白话解释 |
| --- | --- |
| Token | AI 计费的最小单位，约等于一个"词"或半个汉字。一段 1000 字英文 ≈ 1300 token，1000 字中文 ≈ 1500–2000 token。 |
| Input / Output 分开计价 | 几乎所有大模型都对输入和输出分开计费，**Output 通常贵 3–5 倍**。 |
| 上下文窗口 | 一次对话能塞多少 token。窗口越大，单次调用越贵。 |
| 模型分层 | 同一家供应商通常有 mini / standard / pro 三档，单价相差 10–30 倍。 |
| 缓存 / 批处理 | 大型任务可以走 batch / prompt cache，单价能再便宜 50%–80%。 |

> ⚠️ 本附录给的所有具体单价均为**示意范围**，请以你使用的供应商当时官方页面为准。AI 单价每年都在降，但模型分层永远存在。

---

## 三、方法论：三档预算分级法

把所有 AI 任务分成 3 档，对应 3 档模型：

| 档位 | 适用任务 | 推荐模型档 | 月预算占比 |
| --- | --- | --- | ---: |
| **C 档：日常起草** | 写客服初稿、整理周报、翻译、提示词调试 | mini / nano 档（如 GPT-4o-mini、Claude Haiku、Qwen-Turbo） | 20% |
| **B 档：内容生产** | Listing 初稿、广告复盘、评论分析、SOP 起草 | standard 档（如 GPT-4o、Claude Sonnet、Qwen-Plus、DeepSeek-V3） | 60% |
| **A 档：复杂决策** | 战略分析、复杂多跳推理、长文档整合、Agent 调度 | pro / reasoning 档（如 o3、Claude Opus、Qwen-Max、DeepSeek-R1） | 20% |

**用法**：80% 的日常工作应该用 B 档以下解决；只有真正"复杂判断"才升 A 档。如果发现自己每天都在调 A 档，多半是**提示词没拆好**，而不是模型不够强。

## 四、月度预算估算（参考起步线）

> 以下仅为起步参考，按团队规模与日均调用量校准。

| 团队规模 | 月度调用量参考 | 起步预算（USD） | 备注 |
| --- | --- | ---: | --- |
| 1 人单店运营 | 100–300 次 / 月 | $10–$30 | 一两个低价订阅或按量付费即可 |
| 3–5 人小团队 | 1k–3k 次 / 月 | $50–$200 | 建议接 API + 团队共享 key |
| 10 人内含运营/广告/客服/设计 | 5k–15k 次 / 月 | $300–$1000 | 必须有人专门盯账单 |
| 跨境品牌团队 30+ | 30k+ 次 / 月 | $2000+ | 需要预算审批流程 + 月度复盘 |

**红线**：当月度账单 > 团队 1 人月薪的 30%，应触发"成本审查"——重新评估是不是模型选高了、是不是 Output 太长、是不是缓存没开。

## 五、具体省钱手法（按性价比排序）

1. **降模型档**：先尝试在 mini 档把任务做对，做不对再升 standard，最后才升 pro。**一升档单价就 ×10–30**。
2. **缩 Output**：让 AI "只输出表格"、"只输出 100 字以内总结"。Output 是大头。
3. **加缓存 / Prompt Cache**：相同的产品理解卡、评论库、品牌词库，每次调用都贴一遍很浪费——挂 cache 后单价能降 70%–90%。
4. **批处理**：50 条评论分类、100 条客服分类，走 batch API（24h 内返回）通常半价。
5. **结构化输出**：要 JSON 就明确要 JSON，避免 AI 写一堆解释文字（你不需要也得付钱）。
6. **早做截断**：让 AI "如果超过 N 条就停"，避免它兴致勃勃跑出 200 条你根本不看的内容。
7. **本地小模型兜底**：FAQ 分类、敏感词过滤这种重复工作，可以用 7B 级别的本地模型 / 嵌入模型代替——零边际成本。

## 六、案例：3 人小团队广告复盘月度账单（脱敏）

某 3 人跨境团队，主要 AI 任务：每周 1 次广告复盘 + 每天 5 条客服初稿 + 偶尔 Listing 优化。

| 任务 | 频率 | 模型档 | 单次估算 | 月度估算 |
| --- | --- | --- | ---: | ---: |
| 广告复盘 | 4 次 / 月 | A 档 | $0.40 | $1.6 |
| 客服初稿 | 150 条 / 月 | C 档 | $0.01 | $1.5 |
| Listing 初稿 / 修改 | 8 次 / 月 | B 档 | $0.15 | $1.2 |
| 评论批量分类 | 1 批 200 条 / 月 | B 档 + batch | $0.30 / 批 | $0.3 |
| 团队探索性使用（杂） | 不可控 | 混合 | — | $30 |
| **合计起步** | | | | **≈ $35** |

如果他们换成"客服初稿用 A 档 + Listing 用 A 档 + 不开 cache"——同样工作量月度账单可能 $200–$500。**模型档选择 + cache + Output 长度就是 10× 的成本差距**。

## 七、实操：建立你的"AI 月度账本"

```text
| 任务 | 频率 | 模型档 | 单次成本 | 月度成本 | 是否可降档 |
| --- | --- | --- | ---: | ---: | --- |
| ... | ... | ... | ... | ... | ... |
```

要做的事：

1. 列出最近一个月**真的在用** AI 的任务（不超过 10 项）。
2. 标出每项当前用的模型档。
3. 估算月度成本（API 控制台或订阅平摊）。
4. 标出"可降档而不影响质量"的项——这些就是你的省钱杠杆。
5. 设月度预算上限，超过 80% 时设置告警。

## 八、常见误区

| 误区 | 真相 |
| --- | --- |
| "贵的模型一定更好" | 90% 的电商日常任务，mini 档完全够用。 |
| "免费模型省钱" | 反复返工的人时成本，比 API 费用贵得多。 |
| "用一个模型就够了" | 同一团队用 2–3 档模型混搭，效率最高、成本最优。 |
| "Token 数我看不懂" | 控制台都显示，盯一周就有感觉。 |
| "费用是 IT/财务的事" | 用 AI 的人才知道每项任务该不该升档。 |

## 九、与正文章节的关系

- 第 2 章《学会把问题说清楚》：写得好的提示词 = 用更少 token 得到同质量结果，**写提示词的能力就是省钱的能力**。
- 第 10 章《广告数据复盘》：复盘表里可以新增一行"本周 AI 调用成本 / 复盘所节省的人时"做 ROI 自检。
- 第 13 章《SOP》：每份 SOP 应明确"本步骤用哪个模型档"，避免新人下意识用最贵的。
- 第 21 章《结营成果包》：成果包里可加入"月度 AI 账本"作为可见成果。

---

## 十、本附录小结

- AI 不是"工具费"，是可调档的**业务投入**——用得对会创造 5–10× 价值，用错会变成持续失血。
- 三档预算分级 + cache + 控 Output 长度，是 80% 团队最该掌握的省钱手法。
- 每个团队都该有一份月度 AI 账本，哪怕 1 页。
