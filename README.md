# AI 跨境电商效能提升实战课｜课程资料库

这是一个面向跨境电商运营、讲师和学习者的课程资料库。

课程定位是：**务实、温和、可落地、以内啡肽式正反馈为核心**。  
不使用“暴富”“颠覆”“1000%增效”“5人抵50人”等刺激性表达，而是帮助学员通过一个个小成果，建立可持续的效能提升。

## 课程结构

- 第 1 周：先认识 AI，学会把问题说清楚
- 第 2 周：把 AI 放进日常工作
- 第 3 周：完成一个小而真实的改进

## 使用方式

1. 先阅读 `00_课程总纲/`，尤其是 [`11_单源一致性约定.md`](./00_课程总纲/11_单源一致性约定.md)，了解源章节、实操手册、TCI 教材三层的职责分工。
2. 再逐章完善 `01_第1周_AI基础提效周/`、`02_第2周_AI岗位实战周/`、`03_第3周_AI落地陪跑周/`（这三处是 **唯一真源 / Source of Truth**）。
3. 每章的 step by step 实操手册在 `09_章节实操手册/`，适合学员跟着做（派生视图）。
4. 课程讲稿、实操表格、评分表和提示词分别在对应文件夹中。
5. 如果后续继续完善课程内容，建议先阅读 `00_课程总纲/11_单源一致性约定.md`，再修改源章节。

> ⚠️ 改动内容前务必先读单源约定：**概念 / 方法 / 案例只能改源章节**，然后再派生到实操手册与 TCI 教材，禁止在三处互不同步地分别修改。

## 快速阅读

- 课程阅读和分享使用路径见 `00_课程总纲/07_课程阅读与使用指南.md`。
- 资料库阅读器在 `html_reading_package/index.html`，适合查看所有 Markdown 文件。
- 书籍阅读版在 `book_reading_package/index.html`，适合分享给学员像看书一样阅读。
- 根目录会同步生成 `AI跨境电商效能提升实战课_书籍阅读版.html`，这是最适合直接发给别人的单文件版本。
- 书籍阅读版会把 21 个章节和 21 份实操手册放在一起，章节正文可以直接跳转到对应实操手册。
- 图示会在打包时转成内嵌 SVG，不依赖外部 Mermaid CDN。

## 课程设计原则

- 每章只解决一个具体问题。
- 每章都要有交付物。
- 先完成，再优化，再复用。
- 反馈要温和但具体。
- 不排名，只做前后版本对比。
- 不追求炫技，优先提升真实工作效能。

## 推荐完善顺序

1. 完善每章讲稿。
2. 完善每章课堂实操。
3. 完善模板库。
4. 完善评分反馈表。
5. 最后再统一课程语言和视觉风格。
